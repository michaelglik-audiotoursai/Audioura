# Tour Type Detection System - Enhanced Context for Reference Tours

## Problem Analysis
- **Current System**: Works well for operational tours (restaurants, museums)
- **Gap**: Reference tours (books, movies, history) need richer contextual information
- **Example**: "Porter Square T station mentioned in the book" needs specific quotes, scenes, character interactions

## Proposed Solution: Dual Template System

### Step 1: Tour Type Detection
```python
def detect_tour_type(request_string):
    contextual_keywords = [
        'book', 'novel', 'movie', 'film', 'podcast', 'historic figure', 
        'history', 'mentioned in', 'featured in', 'inspired by',
        'character', 'scene', 'episode', 'chapter'
    ]
    
    operational_keywords = [
        'restaurant', 'museum', 'gallery', 'shop', 'store', 'cafe',
        'bakery', 'bar', 'pub', 'hotel', 'theater'
    ]
    
    if any(keyword in request_string.lower() for keyword in contextual_keywords):
        return "CONTEXTUAL"
    elif any(keyword in request_string.lower() for keyword in operational_keywords):
        return "OPERATIONAL"
    else:
        return "OPERATIONAL"  # Default to operational
```

### Step 2: Enhanced Templates

#### Operational Template (Current - Keep As Is)
- Focus: Hours, prices, specific offerings, operational details
- Example: "Open Tuesday-Saturday 10:00 AM - 5:30 PM, admission $15"

#### Contextual Template (New - Enhanced Context)
- Focus: Detailed references, quotes, scenes, historical significance
- Enhanced "Specific Examples" section with contextual depth

### Step 3: Contextual Template Enhancement
```
Contextual References: [Detailed quotes, scenes, or historical context - 3-4 specific examples with rich detail]
- Quote or scene from the source material
- Character interactions or plot significance  
- Historical context or cultural importance
- Specific details about how location appears in source
```

### Root cause

LOCAL-264 placed the tour overview (prolog) inside `_orientation_prefix` — the string beginning `"Orientation: "` — to satisfy Michael's requirement that TTS and translation key on that word. Museum tours then hit R3, which drops the entire orientation block when the stop's orientation text lacks a grounded viewing note. Because `_orientation_prefix` now carried the overview, **R3 dropping a weak orientation on stop 1 deleted the tour overview.**

The fix separates the two concerns: R3 gates only the `_clean_orientation` text. When stop 1 has a prolog and R3 rejects the orientation text, `_orientation_prefix` (overview + "Your first stop is X") is still emitted.

### "L a geste de Bouddha" — broken space investigation

**Finding:** The broken space `"L a geste de Bouddha"` is NOT present in any source data, code, or database in this worktree. All instances of this title in `venue_corpus`, `canonical_titles_json`, and the D1v2 verification path use the correct form `"La geste de Bouddha"`.

**Source:** The T4 transition template uses `next_poi['name']` directly. For museum tours, POI names pass through the D1v2 deterministic fill (which verifies against `canonical_titles_json`). The broken space would only occur if:
1. The LLM returned a malformed name during Phase 3A, AND
2. D1v2 failed to match/correct it (e.g., the gate was temporarily off or the fuzzy match threshold rejected it)

**Evidence:** The tour generated by this fix shows correct spacing throughout: `"La geste de Bouddha"` in all 4 occurrences (overview Part 4, directions, stop header, description).

**Verdict:** Non-deterministic LLM output artifact in a prior run. Not cheaply fixable at the source — would require a post-hoc name sanitizer comparing against canonical titles after Phase 3A. The existing D1v2 gate already provides this protection when enabled; the broken tour likely had the gate off or partially bypassed.

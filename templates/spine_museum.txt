You are a master storyteller and audio-tour architect. Given a museum venue and
its list of stops, produce a narrative SPINE that transforms a list of exhibits
into a single compelling story arc.

VENUE: {{venue_name}}
STOPS ({{total_stops}} total): {{poi_list}}

Return ONLY valid JSON (no markdown fences, no commentary) with this exact schema:

{
  "tour_hook": "An intriguing question or mystery that hooks the listener in the first 10 seconds. It must be answerable by the tour's end.",
  "connecting_thread": "The single thematic thread that ties every stop together — a narrative throughline the listener follows from start to finish.",
  "arc": [
    {
      "stop": 1,
      "name": "<stop name from the POI list>",
      "chapter_role": "<one of: opening | rising | climax | resolution>",
      "emotional_beat": "<the dominant emotion this stop should evoke in the listener>",
      "unique_angle": "<what makes THIS stop's story surprising or fresh — the angle no generic guide would use>",
      "plant": "<a narrative seed planted here that pays off at a later stop (or null if none)>",
      "callback": "<name of an earlier stop this one references back to (or null if first stop)>",
      "cliffhanger": "<a question or tease that compels the listener to continue to the next stop>"
    }
  ],
  "climax_stop": <integer — which stop number is the emotional peak>,
  "resolution_stop": <integer — which stop number resolves the tour_hook>,
  "closing_revelation": "A specific, verifiable fact about this venue or artist that answers the tour_hook — something the visitor can look up and confirm. MUST include a concrete image or action the visitor can carry away (e.g., 'Next time you see X, notice Y'). NEVER use generic words: 'eternal', 'dialogue', 'testament', 'legacy', 'timeless'. Ground it in a real date, number, or documented event."
}

RULES:
1. Every stop in {{poi_list}} MUST appear in the arc array, in order.
2. chapter_role distribution: exactly 1 "opening", 1 "climax", 1-2 "resolution", rest "rising".
3. plant/callback must form a valid chain — never reference a stop that doesn't exist.
4. The tour_hook MUST be answerable by closing_revelation.
5. unique_angle must be specific to the venue and exhibit — never generic ("this is interesting").
6. emotional_beat should vary across stops — avoid repeating the same emotion consecutively.
7. cliffhanger must create genuine curiosity, not a rhetorical question with an obvious answer.
8. All content must be factually accurate for {{venue_name}} — do not fabricate exhibits or history.

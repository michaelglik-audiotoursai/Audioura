### Limitations

1. **The scorer rates both sample tours as 100.0 (all RICH).** This is expected — the test tours are hand-crafted with dense facts. Real generated tours score lower (D200 measured 5.1% RICH, 24.7% ADEQUATE, 70.2% THIN across 1,732 real stops). The integration is correct; the test data is simply high-quality.

2. **`detect_venue_identity()` is narrow.** It only matches patterns for Kenzo Tange / the Asian Arts Museum. Real tours won't get venue_identity_bonus unless LOCAL-304 generalizes this. The scoring module records 0.0 faithfully.

3. **Edit delta counts fact-count differences, not specific sentences.** "sourced_facts_removed=3" means 3 fewer distinct facts in the edited stop — it cannot name which sentences were removed because `analyze_stop` counts facts by regex, not by sentence provenance. A future version tracking per-sentence lineage would enable "the sentence about Queen Victoria's entourage was removed."

4. **No retroactive scoring of existing 29 production tours.** This task scores at generation time. Scoring the backlog requires a one-off script (out of scope).

5. **`tour_editing_phase2.py` re-scoring requires `derived_from_tour_id`.** If a client promotes a tour without specifying which original it derives from, no delta is computed. The scoring still runs (just not as a re-score with delta).

# LOCAL-705 (D661) — storied-compat allow-list.
#
# Every lib/ file that makes a RAW server call (http.get/post/put/delete or
# Endpoints.get/post/put/delete, i.e. NOT the *OrFeatureUnavailable helpers)
# must appear here with a one-line reason, OR the call must be routed through a
# helper. storied_compat_guard_test.dart enforces this and also fails on a
# STALE entry (a file that no longer has a raw call), so this list stays honest.
#
# A reason answers: "why does this raw call NOT crash the app on a Storied
# (Stable) backend that may lack the route or the whole service?" The two
# acceptable shapes are:
#   • CORE  — the endpoint IS hosted by Storied (map/search/download/generate/
#             status/rating/translate/share/sync); the call is still wrapped so
#             a transient error degrades, but the feature is expected to work.
#   • SAFE  — the method wraps the call in try/catch and returns a safe default
#             (null / [] / false / an error-result object / an empty state) on
#             ANY non-2xx or transport error, so a missing route or absent
#             service shows an empty state, never a crash.
# Format:  <path relative to lib/> | <reason>

services/background_service.dart | CORE /status + /download polling for a backgrounded generate; wrapped in try/catch, acts only on 200.
services/background_tour_monitor.dart | CORE /status + /download polling; try/catch, acts only on 200.
services/tour_translation_helper.dart | CORE download of a translated tour + translate POST; try/catch, 200-gated.
services/tour_rating_service.dart | CORE POST/GET /tour/<id>/rating; typed catches (Socket/Timeout/Client) -> null, outbox-queued offline.
services/tour_status_service.dart | CORE PUT /user + POST /tour-status tracking; try/catch -> void/'' on any failure.
services/translation_service.dart | CORE POST /translate-with-audio; try/catch -> {status:error,message} map, never throws to the UI.
services/outbox_service.dart | CORE POST /sync of queued events; typed catches -> null (keep + backoff), 4xx/5xx kept not lost.
services/tour_share_service.dart | SAFE explicit handler — Endpoints.post then isRouteMissing(status,body); route-missing/absent -> Preview message (tested storied_compat_services_test.dart).
